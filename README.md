# 🤖 DecodeLabs Smart AI Assistant

A simple **Rule-Based AI Chatbot** built using **Python** and **Streamlit**. The chatbot can answer basic AI-related questions, perform calculations, tell jokes, share motivational quotes, display fun facts, and conduct a simple AI quiz through an interactive web interface.

---

## 🚀 Features

- 💬 Interactive Chat Interface
- 🤖 AI & Python Information
- 🧮 Smart Calculator
- 😂 Random Jokes
- 💡 Motivational Quotes
- 🌍 Fun Facts
- 🧠 AI Quiz
- 📅 Current Date & Time
- 📊 Session Statistics
- 📝 Chat History

---

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Rule-Based-AI-Chatbot.git
```

Go to the project folder

```bash
cd Rule-Based-AI-Chatbot
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
